### Fix Firefox stutter caused by Nvidia driver protocol change #Linux

- Issue:
    - >   Mutter 50.4 negotiates the linux-drm-syncobj-v1 explicit-sync protocol with your NVIDIA 580.178.04 driver; that path's acquire/release fence handling stalls discrete
      commits — focus changes, tab opens, first repaint after activation — while sustained pipelined rendering flows fine. That's why every trigger was an event and never a
      workload, why Chrome (different present-path timing) stayed smooth, and why all my sustained-load instrumentation read clean. The env var is NVIDIA's own kill switch
      for the syncobj path, falling back to implicit sync — the standard behavior before the 555 driver series introduced explicit sync.
- solution for `mutter#3720` — "NVIDIA 580.178.04 + mutter 50.4 + Firefox 155, focus-commit stalls eliminated by  __NV_DISABLE_EXPLICIT_SYNC=1"
- ```
   #!/bin/bash
   # apply-nvidia-firefox-fix.sh
   # Scopes Firefox to implicit sync (__NV_DISABLE_EXPLICIT_SYNC=1) to kill
   # focus-switch / new-tab / urlbar stalls caused by the explicit-sync
   # present path (mutter linux-drm-syncobj-v1 + NVIDIA 580.x, mutter#3720).
  set -euo pipefail
  SRC=/usr/share/applications/org.mozilla.firefox.desktop
  DST_DIR=$HOME/.local/share/applications
  DST=$DST_DIR/org.mozilla.firefox.desktop
  [[ -f $SRC ]] || { echo "source desktop file not found: $SRC" >&2; exit 1; }
  mkdir -p "$DST_DIR"
  cp "$SRC" "$DST"
  # Prefix every Exec= line with the env var (idempotent: skip if already wrapped)
  sed -i 's|^Exec=\([^e]\)|Exec=env __NV_DISABLE_EXPLICIT_SYNC=1 \1|' "$DST"
  sed -i 's|^Exec=firefox|Exec=env __NV_DISABLE_EXPLICIT_SYNC=1 firefox|' "$DST"
  update-desktop-database "$DST_DIR" 2>/dev/null || true
  echo "installed: $DST"
  grep '^Exec' "$DST"
  ```
- Revert script (companion):
    - ```
      #!/bin/bash
      # revert-nvidia-firefox-fix.sh
      rm -f "$HOME/.local/share/applications/org.mozilla.firefox.desktop"
      update-desktop-database "$HOME/.local/share/applications" 2>/dev/null || true
      echo "reverted — system desktop file is authoritative again"
      ```
- command line wrapper
    - ```
      mkdir -p ~/.local/bin
      cat > ~/.local/bin/firefox <<'EOF'
      #!/bin/bash
      export __NV_DISABLE_EXPLICIT_SYNC=1
      exec /usr/bin/firefox "$@"
      EOF
      chmod +x ~/.local/bin/firefox
      ```
