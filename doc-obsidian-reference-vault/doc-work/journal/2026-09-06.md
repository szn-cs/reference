# AFFiNE

#tool
- Affine has its entire codebase including proprietary server components source available; Limitations on users and storage can be modified and rebuilt to self-host;
- Issues:
    - Logseq allows you to define complex, relational metadata for a singular block; much more granular model and classification;
    - While AFFiNE and Confluence are technically composed of blocks or elements, they do not support assigning custom taxonomy or metadata tags directly to an individual block within a page.
    - Cannot detect orphan documents; There is no strict relationship hierarchy; How do you associated a sub-document with an owning parent document which should be always acted on together;
- [https://docs.affine.pro/self-host-affine/install/docker-compose-recommended](https://docs.affine.pro/self-host-affine/install/docker-compose-recommended)
- ```
  claude mcp add --transport http affine     "http://localhost:3010/api/workspaces/<workspace_id>/mcp"     --header "Authorization: Bearer
    <token>"])
  ```
