# comparing note taking apps

#ideas [[2026-07-05#^improvement-to-logseq-concept-logseq-excels-at-organizing]]
- AFFine, LogSeq, Obsidian: looks like  the LogSeq chronological approach to journaling and being able to create pages from the journal is a killer feature which makes writing notes quick and hassle free;
- Rethinking a new knowledge base note taking app that get things right by providing a clear workflow for creating notes without customization hell; The idea is to always begin from a single timeline track where each note/page must be assigned a date of creation/ownership; the timeline can be split into segregated groups by annotating the note/page with group/track timeline annotations (can be called a collection); labels are colored tag annotations on the blocks/pages; Blocks are stored in hierarchies with parent-child relationship; top most block can be annotated with page wrapper type; The idea is to be able to start of from the timeline and navigate through different aspects of work; Because the timeline view is the core of all content and allowing to view content in a chronological order makes managing it natural; A collection can have different views among which is workspace view where hierarchies and pages drive the order instead of timeline;
- [Q] How do you arrange people? a timeline that records when person added? association with a period of life or area of interest or projects?
- [Problem] Obsidian approach to structuring forces the user to be the librarian; any automated daily/weekly/monthly pages and notes association is custom plugins and manual work still required to keep it consistent; It also does not integrate into the app interface well; If AI is allowed to create folders and pages arbitrarily without user's organization it would quickly messup the storage and make navigation impossible overtime with quality degrading overtime requiring constant reorganization  (it is still useful to instruct it to extract people/companies identities for example to create new cards for them but it must be specifically instructed how to do so);
- [Problem] Obsidian is not tailored towards token efficient retrieval of knowledge - it has to go through raw files indexing; The AI would need to hop over a lot of pages in order to extract the information;
- Because generating embedding frequently are costly (usually a periodic schedule for embedding are processed on all day's notes together), a combined approach of raw file context of today + augmented retrieval can be used to increase accuracy of results;
- Observability into what the AI agent is doing or tracing actions it took is important to review and verify the system is working correctly;
- The issue with logseq is that it breaks when modifying files outside of the Logseq software, because logseq create an ID for each block, when it doesn' t find it or a mismatch happens it can fail recovering;
