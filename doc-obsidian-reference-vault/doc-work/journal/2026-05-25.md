    - > Process Architecture & Lifecycle Differences
      > **Zed ACP (Decoupled, GUI-Bound)**
                        - Architecture: Runs as an isolated Node.js subprocess (@zed-industries/claude-code-acp) managed by Zed.
                        - Communication: Inter-process communication (IPC) via JSON-RPC over stdin/stdout or local sockets.
                        - Lifecycle: Tied strictly to the editor. Boots/terminates alongside Zed's Agent Panel UI threads.
                          **Claude Agent SDK (Embedded, Headless)**
                        - Architecture: In-process library (TS/Python) embedded directly within your application runtime.
                        - Communication: Zero IPC overhead; manages state in-memory and communicates natively with Anthropic endpoints via HTTP/WebSockets.
                        - Lifecycle: Developer-controlled. Runs headlessly via scripts, CLIs, or CI/CD pipelines independent of an IDE.
