# Nvidia driver - Origin

- Fedora 44 Nvidia driver installation [https://rpmfusion.org/Howto/NVIDIA](https://rpmfusion.org/Howto/NVIDIA)
  #Linux
    - Pascal GPU [https://rpmfusion.org/Howto/NVIDIA#Legacy_GTX_800.2F900.2F10](https://rpmfusion.org/Howto/NVIDIA#Legacy_GTX_800.2F900.2F10)
        - ```
          dnf update -y
          sudo dnf install xorg-x11-drv-nvidia-580xx akmod-nvidia-580xx
          ```
    - **install suspend scripts for Nvidia**
        - ```
          sudo dnf install xorg-x11-drv-nvidia-580xx-power
          sudo systemctl enable nvidia-{suspend,resume,hibernate}
          echo deep | sudo tee /sys/power/mem_sleep
          systemctl suspend
          ```
