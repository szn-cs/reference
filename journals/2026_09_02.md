		  **Standard JWT Claims for Actor & Session IDs**
		  modern OAuth 2.0 / OpenID Connect (OIDC) tokens often encode both actor identity and session identity (OIDC and IETF extensions) using JWT;
		  
		  | Concept | Standard JWT Claim | Specification | Description |
		  | --- | --- | --- | --- |
		  | **User / Principal ID** | `sub` *(Subject)* | RFC 7519 (JWT) | Identifies the primary user or entity whom the token represents. |
		  | **Actor ID** (optional) | `act` *(Actor)* | RFC 8693 (OAuth 2.0 Token Exchange) | Identifies the active party performing an action *on behalf of* the `sub` (e.g., support admin, service account, or AI agent). |
		  | **Session ID** | `sid` *(Session ID)* | OIDC Front/Back-Channel Logout Specs | Identifies the specific active browser/device login session issued by the Authorization Server. |
