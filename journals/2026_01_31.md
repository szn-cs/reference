		- Another aspect to consider is the Agent session length (runtime limit) while waiting executing the plan. Note that E2B doesn't provide agent hosting only sandbox tool + SDK around it; Blaxel agent hosting required the a continuous connection to stay running, and background async is limited to 10mins.
			- > | **Feature** | **Blaxel (Sync Agent)** | **Blaxel (Async Agent)** | **Blaxel (Batch Job)** | **E2B (Sandbox)** |
			  | ---- | ---- | ---- |
			  | **Max Duration** | **~100 Seconds** | **10–15 Minutes** | **24 Hours** | **24 Hours** (Pro) |
			  | **Response Type** | Immediate (Stream) | Ack + Callback | Polling / Events | Persistent Session |
			  | **Idle Behavior** | Scales to Zero | Scales to Zero | Terminates on finish | Stays running |
			  | **Boot Speed** | 25ms | 25ms | Minutes (Cold boot) | ~150ms |
			  | **Billing Model** | Per request/ms | Per request/ms | Per compute hour | Per session hour |
