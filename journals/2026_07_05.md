- Improvement to Logseq concept: Logseq excels at organizing information chronologically through daily journal entries. However, it lacks a native way to organize project or pipeline tasks as a chronological sequence that spans multiple days. While individual tasks can be linked or tagged, there is no dedicated timeline view that presents a project's tasks in execution order or as an evolving workflow from start to finish. 
  #ideas/logseq
	- one default timeline for free day tasks; another timeline/tree for tasks tide to a project;
	- additionally an option to add items, external references, and metadata that is used only in the moment as a long-period scratchpad; This information should not be index-able and after completion would be collapsed to few notes;
		- e.g. claude code active sessions/branches for the task;
	- **Workstream** - a group of tasks being worked on spanning multiple chronological days; Support a workstream that can be referenced in many days, without disintegrating items but preserving the chronological order which the tasks are added;
