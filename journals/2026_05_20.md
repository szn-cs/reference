		- > Agent harness vs framework: a harness owns the loop. It decides whether a tool call executes, enforces budgets, manages context, and provides observability. A framework gives you the building blocks to construct that loop yourself. An SDK connects you to someone else's loop. As Analytics Vidhya's taxonomy puts it: frameworks provide building blocks, runtimes execute workflows, harnesses enforce control.

	  ### 📦 Key AI Frameworks & Libraries in Rust
	  
	  * **RIG (Rust Inference Engine)**: A modular, ergonomic library built to deploy scalable LLM-powered applications. Acting as an idiomatic "LangChain for Rust," it natively leverages Rust's type system to support workflows like multi-turn conversations, vector stores, and streaming across major cloud providers.
	  * **Burn**: A flexible, fully-featured deep learning framework written entirely in native Rust, aiming to provide an alternative to PyTorch for training and deployment.
	  * **Candle**: Developed by Hugging Face, this is a minimalist ML framework for Rust focused on performance and ease of deployment for running local inference on weights.
	  * **tch-rs**: Direct Rust bindings for the C++ API of PyTorch, allowing you to use existing PyTorch models inside high-speed Rust applications.
	  * **Linfa & ndarray**: Linfa provides a classical machine learning toolkit modeled after Python's scikit-learn, while ndarray provides the n-dimensional arrays required for heavy math operations.
