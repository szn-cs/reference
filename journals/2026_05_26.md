			- **GitLab CE (Community Edition)**
				- **GitHub Stars:** ~24.8k
				- **Launch Year:** 2011 *(Modern YAML-based GitLab CI was integrated in 2015)*
				- **Core Focus:** An all-in-one DevOps platform featuring deep merge request integration and highly flexible pipeline architecture.
			- **Argo Workflows**
				- **GitHub Stars:** ~14.5k
				- **Launch Year:** 2017
				- **Core Focus:** A Kubernetes-native workflow engine optimized for orchestrating parallel tasks and complex compute graphs (DAGs) using K8s Custom Resources.
			- **Tekton Pipelines**
				- **GitHub Stars:** ~9.0k
				- **Launch Year:** 2018 *(Spun out of Google's Knative project)*
				- **Core Focus:** A highly modular, cloud-native framework that extends the Kubernetes API to run isolated build tasks inside dedicated Pods.
			- **Concourse CI**
				- **GitHub Stars:** ~7.8k
				- **Launch Year:** 2014
				- **Core Focus:** An infrastructure-as-code-first CI engine that eliminates UI configuration drift through strict dependency-driven, stateless execution.
			- **Woodpecker CI**
				- **GitHub Stars:** ~7.2k
				- **Launch Year:** 2021 *(Originates from the 2014 Drone CI codebase)*
				- **Core Focus:** A community-driven, ultra-lightweight engine that executes every single pipeline step inside standard Docker containers.
			- **Forgejo Actions**
				- **GitHub Stars:** ~4.3k *(Main project repository)*
				- **Launch Year:** 2022
				- **Core Focus:** A built-in, self-hosted alternative to GitHub Actions that uses the exact same YAML syntax and runs via containerized agents.
