- # SDK product - Agentic workspace edgeless medium as the driving interface for agent interaction
  collapsed:: true
  #ideas
	- information knowledge bases (such as blocks & references representations) + edgless/growable space interface (such as infinite canvas) + timeline scale can form the future environment where agents present status and results to the users and interact on shared resources through a multi-session span;
	- Many product ideas which require flexible interfaces to tailor the presentation for the current momentary need of the user; Users usually rely on multiple sources with different interfaces - discovery/inspiration, search/filter, verify/answer, etc. Platform solutions using AI agents many aggregate the diverse interfaces under the same screen for better accessibility, guidance, and focus;
	  collapsed:: true
		- A user wants to make a decision -> agent workspace presents guidance -> user interacts with given information to gain confidence -> agents refines direction and provides call for action (book a flight/hotel, reserve/buy items, etc.);
		- The medium supports many web-components tailored for each use-case that are displayed on demand by agent and tracked during a session on the edgeless timelined space with live momentary information, and relevant details/decisions are preserved in a knowledge database for later review;
		- e.g. layla.ai travel planner (visual discovery, ai converstion, search/filters); e-commerce discovery/search of products;
	- Session canvas for interactive guidance/discovery/steer of information & direciton; while a document is used as source-of-truth record of the refined decisions & intent;
	  collapsed:: true
		- Agents through the process of iterative guidance provide reassurance for initially hesitant users to commit to a final decision/action (purchase/commit/schedule/reserve etc.);
		  collapsed:: true
			- rough direction/idea, hesitation -> decisive/confident decision, commit to action;
	- Humans confirmation can be added to the workflow - users may request specialist human confirmation on big purchases (e.g. a human travel advisor can confirm the details and finalize the booking of AI generated itinerary);
	- The technology stack can be attractive to the next generation of apps built around AI agents as primary interaction entrypoint; Human -> Ai Agent -> Canvas app interface;
	- A flexible canvas interface can enrich presentation with diagrams, which are especially useful for planning or explaining connections of options and restricting decision options to what requirements constrain;
	  collapsed:: true
		- e.g. exploring solar energy products for home: what type of architecture is recommended? what type of inverter? if this type is choosen then it limits other decision options down the line; Is it compatible with this product? etc.
