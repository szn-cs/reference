- ### concept of React server rendering https://react.dev/reference/rsc/server-components
	- server side rendered components (Nextjs + React server components) or compile-time rendering; very similar to PHP webpage templating approach (Apache + PHP templaing).
	- render on server, stream html, keep client light (faster initial render, less JS to run).
	- similar concept https://tanstack.com/start/latest/docs/framework/react/guide/server-functions write a function in a server context, and the framework automatically handles the networking and serialization required to call (RPC) that function from the client.
