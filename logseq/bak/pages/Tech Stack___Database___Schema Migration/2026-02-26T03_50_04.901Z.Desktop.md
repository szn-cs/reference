		- Refinery is forward only (no rollback sql is supported) but migrations are applied each in a database transaction (failure will not persist migration change).
			- #+BEGIN_QUOTE
			  Rollbacks: Migration tools like Refinery (inspired by Flyway) often don't support automatic rollbacks. The recommended practice is to treat a rollback as a new forward migration to keep the history append-only and avoid relying on potentially untested "down" scripts.
			  #+END_QUOTE
